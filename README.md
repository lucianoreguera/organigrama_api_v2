## Descripción

API REST para la gestión del organigrama municipal de Catamarca.

## Configuración del proyecto

```bash
$ yarn install
```

## Levantar base de datos

```bash
# database
$ docker-compose up -d
```

## Compilar y ejecutar el project

```bash
# development

$ yarn run start

# watch mode

$ yarn run start:dev

# production mode

$ yarn run start:prod
```
